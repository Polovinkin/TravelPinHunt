# Tailwind CSS

В этой папке находятся инструменты для сборки Tailwind CSS. Они нужны только
разработчику и не загружаются браузером при открытии сайта.

### Файлы

`package.json`- Создан вручную. Содержит:

- зафиксированную версию Tailwind CSS;
- команду `build:css`, которая собирает итоговый CSS сайта.

`package-lock.json` - Автоматически создаётся командой `npm install`. Содержит точные версии Tailwind
и всех его внутренних зависимостей, а также контрольные хеши скачиваемых пакетов.

Вручную редактировать этот файл не нужно. Он не загружается на сайт.

`tailwind.config.js` - Создан вручную. Указывает Tailwind:

- в каких Django-шаблонах и Python-файлах искать CSS-классы;
- что тёмная тема включается классом `.dark`;
- какой набор шрифтов используется для `font-sans`.

`tailwind.input.css` - Создан вручную. Это входной файл сборки с директивами Tailwind и локальным подключением шрифта `static/fonts/NunitoSans-Variable.ttf`.

`node_modules/` - Автоматически создаётся командой `npm install`. Содержит Tailwind и его
внутренние инструменты сборки. Папка добавлена в `.gitignore`, не попадает в Git
и не загружается на сайт. После сборки её можно удалить.

### Сгенерированный CSS

Итоговый файл находится не здесь, а в:

```text
static/tailwind.css
```

Он автоматически создаётся Tailwind, минимизирован для production и поэтому
выглядит как одна длинная строка. Вручную редактировать его не нужно.

Этот файл необходимо коммитить: production-деплой не устанавливает Tailwind, а
Django `collectstatic` забирает уже готовый CSS из папки `static`.

### Как пересобрать CSS

После нового клонирования репозитория или удаления `node_modules` сначала
установить инструменты:

```bash
npm install --prefix tools/tailwind
```

После добавления или изменения Tailwind-классов в шаблонах либо Python-файлах
пересобрать CSS:

```bash
npm --prefix tools/tailwind run build:css
```

После сборки нужно добавить обновлённый `static/tailwind.css` в коммит.
